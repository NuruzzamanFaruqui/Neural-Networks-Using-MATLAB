# Data sources

All data files are small plain-text CSV files and sit next to the scripts that use them. They come from public sources. Each file keeps the licence of its original source.

| File | Used in | What it is | Original source |
|---|---|---|---|
| `iris.csv` | Chapters 4, 5, 9 | 150 iris flowers, 4 measurements, 3 species | Ronald Fisher (1936), UCI Machine Learning Repository |
| `diabetes.csv` | Chapter 9 | Disease-progression data for 442 patients | Efron, Hastie, Johnstone and Tibshirani (2004) |
| `cancer.csv` | Chapter 10, P1 and P6 | Wisconsin diagnostic breast cancer data, 569 tumours | UCI Machine Learning Repository |
| `cars.csv` | Chapter 10, P2 | Auto MPG data, cars sold between 1970 and 1982 | StatLib, Carnegie Mellon University (also on UCI) |
| `wine.csv` | Chapter 10, P3 | 178 Italian wines, 13 chemical measurements, 3 cultivars | UCI Machine Learning Repository |
| `ratings.csv`, `movie_titles.txt` | Chapter 10, P4 | Film ratings | MovieTweetings collection |
| `weather.csv` | Chapter 10, P5 | Daily Seattle weather records | NOAA |
| MNIST (downloaded) | Chapters 6 and 7 | 10,000 handwritten digits (test set) | Yann LeCun, Corinna Cortes and Christopher Burges. Run `setup_mnist.m` |
